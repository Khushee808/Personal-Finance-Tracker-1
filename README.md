# Personal Finance Tracker — Advanced GitHub Version

## Original features
Register, Login, Logout, Dashboard, Income/Expense transactions, categories, recurring checkbox, budget, savings goal, charts, transaction history, reports, CSV/PDF print, settings and dark mode.

## Added 4 advanced features
1. Category-wise budgets with progress bars and over-budget warning.
2. Smart financial insights on the dashboard.
3. Savings-goal progress tracking.
4. JSON Backup & Restore from Settings.

## GitHub Pages
Upload all files in this folder to a GitHub repository. Settings → Pages → Deploy from branch → main → root → Save.

This is a static college-project demo. Data is stored in the browser using localStorage; login is not production-grade authentication.

## Dashboard additions
- Income vs Expense chart
- Expense Categories donut chart
- Recent Transactions preview with View All & Filter
